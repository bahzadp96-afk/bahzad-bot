# ڕێبەری تەواوی بۆتی زیرەکی دەستکرد بۆ پەیجی فەیسبووک (Facebook Messenger AI Bot)

ئەم بەرنامەیە بۆتێکی پێشکەوتووی زیرەکی دەستکردە بە زمانی **کوردی (سۆرانی)** کە ڕاستەوخۆ دەبەسترێتەوە بە مێسنجەری پەیجی فەیسبووکی دوکانی مۆبایلەکەتەوە.

---

## 🎯 تایبەتمەندییەکان
1. **وەڵامدانەوەی کێشەکانی مۆبایل**: چارەسەری کێشەکانی ئایفۆن و ئەندرۆید، پاتری، شاشە، فۆرمات، ئەپڵ ئایدی، جیمەیڵ، تێکچوونی سیستەم.
2. **وەڵامدانەوەی کێشەکانی سۆشیاڵ میدیا**: پاراستنی هەژمارەکانی فەیسبووک، ئینستاگرام، سناپچات، تیکتۆک، تێلیگرام، کۆدی 2FA و هاکبوون.
3. **پرسیاری ڕۆتینی دوکان**: کاتی دەوام، ناونیشان و شوێن، خزمەتگوزارییەکان.
4. **ڕێسای تایبەت بە نرخ (Price Guard)**: بە هیچ جۆرێک نرخ ناڵێت، بەڵکو داوا لە کڕیار دەکات نامە بۆ ئەدمین بنێرێت یان سەردانی دوکان بکات.
5. **مێژووی گفتوگۆ (Chat Memory)**: وەڵامەکانی بەستراوەن بە یەکەوە و لە پرسیاری پێشوو تێدەگات.
6. **داشبۆردی ناوخۆیی بۆ تاقیکردنەوە**: لە ڕێگەی وێبگەڕەکەتەوە دەتوانیت پێش پەیوەستکردن تاقی بکەیتەوە.

---

## 🛠️ پێداویستییەکان

1. **کلیلی Gemini API (بێبەرامبەر)**:
   - بڕۆ بۆ: [Google AI Studio](https://aistudio.google.com/)
   - کلیلی `Get API key` دابگرە و کۆپی بکە.

2. **تۆکنی فەیسبووک (Facebook Page Access Token)**:
   - لە ڕێگەی پۆرتاڵی [Meta for Developers](https://developers.facebook.com/) وەردەگیرێت.

---

## 🚀 چۆنیەتی دامەزراندن و کارپێکردن

### هەنگاوی یەکەم: دانانی کلیلی نهێنی
فایلی `.env` بکەرەوە و زانیارییەکانت بنووسە:
```env
PORT=3000

# کلیلی فەیسبووک (دوای دروستکردنی ئەپ وەریدەگریت)
PAGE_ACCESS_TOKEN=YOUR_FACEBOOK_PAGE_ACCESS_TOKEN
VERIFY_TOKEN=my_secret_mobile_bot_verify_token_2025

# کلیلی زیرەکی دەستکردی گووگڵ جێمینای
GEMINI_API_KEY=YOUR_GEMINI_API_KEY_HERE
GEMINI_MODEL=gemini-1.5-flash

# زانیارییەکانی دوکانەکەت
SHOP_NAME=ناوی دوکانەکەت
SHOP_ADDRESS=ناونیشانی تەواوی دوکانەکەت
SHOP_PHONE=0750XXXXXXX
SHOP_HOURS=هەموو ڕۆژێک لە ٩:٠٠ی بەیانی تا ١٠:٠٠ی شەو
```

### هەنگاوی دووەم: کارپێکردنی بەرنامەکە
لە تێرمیناڵدا بنووسە:
```bash
npm start
```
یان بە شێوازی گەشەپێدان:
```bash
npm run dev
```

دواتر بڕۆ بۆ وێبگەڕەکەت: **`http://localhost:3000`** بۆ ئەوەی چات لەگەڵ بۆتەکە بکەیت و تاقی بکەیتەوە.

---

## 🌐 ڕێبەری هەنگاو بە هەنگاوی بەستنەوە بە فەیسبووک (Meta Developers)

### ١. دروستکردنی ئەپ لە فەیسبووک:
1. بچۆ بۆ ماڵپەڕی **[developers.facebook.com](https://developers.facebook.com/)** و بە هەژماری خۆت داخڵ ببە.
2. کلیک لەسەر **My Apps** بکە و دوگمەی **Create App** داگرە.
3. هەڵبژاردنی **Other** یان **Business** و پاشان جۆری **Business** هەڵبژێرە.
4. ناوێک بۆ ئەپەکەت دابنێ (نموونە: `Mobile Shop Bot`) و کلیک لە **Create App** بکە.

### ٢. زیادکردنی بەرهەمی مێسنجەر (Messenger Product):
1. لە بەشی چەپ یان لە داشبۆردەکە، بەشی **Messenger** بدۆزەرەوە و کلیک لەسەر **Set Up** بکە.
2. لە پەڕەی ڕێکخستنی Messenger، بڕۆ خوارەوە بۆ بەشی **Access Tokens**.
3. کلیک لەسەر **Add or remove Pages** بکە و پەیجە فەیسبووکەکەت هەڵبژێرە.
4. دوای بەستنەوە، دوگمەی **Generate token** لە تەنیشت پەیجەکەت لێبدە و ئەو تۆکنە درێژە کۆپی بکە و بیخەرە ناو `PAGE_ACCESS_TOKEN` لەناو فایلی `.env`.

### ٣. کردنەوەی ڕاڕەوی ئینتەرنێت (Public Webhook URL):
بۆ ئەوەی فەیسبووک بتوانێت نامەکان بنێرێت بۆ کۆمپیوتەرەکەت پێویستت بە بەستەرێکی ئینتەرنێتە (HTTPS).
دەتوانیت خزمەتگوزاریی **ngrok** بەکاربهێنیت:
```bash
npx ngrok http 3000
```
ئەمە بەستەرێکت دەداتێ بەم شێوازە: `https://abcd-1234.ngrok-free.app`

### ٤. پەیوەستکردنی Webhook لە مێتا:
1. لە پەڕەی ڕێکخستنی Messenger لە Meta Developers، بەشی **Webhooks** بدۆزەرەوە.
2. کلیک لە **Add Callback URL** یان **Edit Callback URL** بکە.
3. لە بەشی **Callback URL** ئەمە بنووسە: `https://abcd-1234.ngrok-free.app/webhook` (ناونیشانی ngrokـەکەت لەگەڵ `/webhook`).
4. لە بەشی **Verify Token** بنووسە: `my_secret_mobile_bot_verify_token_2025` (ئەوەی لە ناو `.env` داتناوە).
5. کلیک لە **Verify and save** بکە (دەبێت سەوز ببێت ✅).
6. کلیک لەسەر **Add Subscriptions** بکە و ئەم دوو بژاردەیە هەڵبژێرە:
   - `messages`
   - `messaging_postbacks`
7. لە بەشی سەرەوەی Webhooks، لە تەنیشت پەیجەکەت دوگمەی **Subscribe** دابگرە تا پەیجەکە پەیوەست ببێت بە وێبهوکەکە.

## ☁️ میوانداریکردنی بەردەوام (Hosting 24/7 بێ کۆمپیوتەر)

ئەگەر ویستت بۆتەکە بەردەوام کاربکات بەبێ ئەوەی پێویست بکات کۆمپیوتەرەکەت کراوە بێت:
- دەتوانیت پرۆژەکە لەسەر سێرڤەرێکی بێبەرامبەری وەک **[Render.com](https://render.com/)** یان **[Railway.app](https://railway.app/)** دانێیت.
- بەستەری ڕاستەوخۆی Render (وەک `https://my-shop-bot.onrender.com/webhook`) لە وێبهوکی فەیسبووک دابنێیت.
